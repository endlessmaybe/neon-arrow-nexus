## 4. 高级功能验收

当前正式 Python 版已实现并验证：

- 每次启动强制先进入“基础 / 进阶 + 简单 / 中等 / 终极困难”选择页；
- 基础模式使用作业原始的单格四方向箭头，只做直线到边界的阻挡判断；
- 进阶模式继续使用 2–4 格随机长箭与折光/反相/双跃迁/阶段相位锁；
- 存档不会绕过启动选择；选中与存档一致的模式和难度后才提供“继续上次进度”；
- 游戏过程中可点击侧栏“切换难度 D”或按 `D` 打开三档难度面板；切换会保留当前基础/进阶规则集，但重新随机当前单关，面板打开期间倒计时和 AI 暂停；
- 实时积分、连击、倒计时、稳定度和量子能量；
- 通关 1–3 星评价；
- `H` 安全箭提示已从最终界面和快捷键中移除；
- `U` 撤销上一步；
- 自动保存和恢复进度；
- 随机生成且保证存在完整解序的关卡；
- `A` AI 自动求解当前关；
- 悬停只做当前箭视觉高亮，不显示安全/危险、阻挡点或正确路径；
- 成功点击后箭头先沿最终朝向前进，箭身沿原折线路径逐段跟随并拉直，再继续出屏；正常模式约 0.86 秒，后段明显淡出；最后一箭离场完成后再显示结果层；
- `V` 低动态模式：跳过启动序列、冻结持续装饰运动并减少粒子，同时保留文字/颜色状态；
- 粒子、稀疏动态星点、折光门旋转、跃迁环脉冲等必要反馈；
- 约 1.15 秒的简化启动同步序列和箭体离场空间反馈；
- 背景删除扫描线、光谱丝带、轨道圈与透视网格；面板、按钮、棋盘统一为单层低装饰层级；
- P1 / P2 / P3 相位锁会按剩余箭数动态显示封锁/解除状态；
- 程序运行时动态生成音效，不依赖外部音频素材；
- `O` 量子超载；
- `R` 重开当前关；
- `M` 音效开关。

实战侧栏的 8 个核心控制现在统一使用 Pygame 原生矢量线条图标，不依赖 emoji 或外部 PNG；按钮同时显示文字和快捷键，鼠标悬停时会显示用途说明卡片。图标、文字、快捷键和说明由同一份 `CONTROL_HELP` 语义映射维护，禁用状态也会同步降低强调度。

低动态和音效开关进入自动存档的 `settings` 字段，专项测试会重新创建应用实例验证恢复结果，不只检查内存变量。

### 渲染性能复测

在同一台机器、同一 Python / pygame-ce 环境、`SDL_VIDEODRIVER=dummy`、窗口 **1600×1000**、连续渲染 120 帧的基准下：

```text
优化前：18.657 ms / frame  ≈ 53.6 FPS
优化后： 7.729 ms / frame  ≈ 129.4 FPS
```

单帧渲染耗时下降约 **58.6%**。主要优化不是降低画质，而是消除重复工作：静态背景渐变/雾化、文本表面、光晕、棋盘网格和布局几何加入缓存；箭路、机关和粒子使用的全屏透明 Surface 改为复用并清空；空粒子队列不再创建特效层。正式运行仍锁定 60 FPS，因此这部分优化主要用于降低 CPU/GPU 提交压力并提高窗口缩放和高密度终极关卡下的余量。

## 5. 两套规则的可解性与占格一致性

基础和进阶两套模式都使用“构造时同时保留合法消除关系”的思路，所以随机地图不是“随机出来后碰运气”。

基础模式的每支箭在逻辑上只占一个格子。新箭只有在面对当前已放置箭阵时沿自身方向可以直接到达边界，才会被加入；最终把构造顺序倒过来即可得到完整解序。三档基础难度分别为 18–22、28–34、40–48 支单格箭，统一无折光门、跃迁环和相位锁。视觉上的短箭身仅用于辨认方向，不会进入多格占用表。

进阶模式继续使用原来的反向构造和阶段验证。普通档可以直接沿构造关系得到完整解序；终极困难因为相位锁会随剩余箭数变化，还会按当前阶段重新推导完整安全路径。自动测试会重新执行该解序。

第三关已撤销随机回溯唯一解依赖链，继续使用真实随机长箭生成器。每根箭实际占用 2–4 个连续格子，紧邻箭头的最后一段与箭头方向一致，前面的身体可以继续直行或随机 90° 转折。最终终极困难棋盘扩展为 13×16，箭数提高到 38–42 条；箭体不会与其它箭或机制格重叠，因此视觉上的长线条同时也是真实碰撞实体。

显示层直接把这些真实身体格中心连接起来，不再生成单格内的装饰性 `visual_route`。2 / 3 / 4 个占用格对应可见的 1 / 2 / 3 格跨度，长短差异非常直接；命中检测覆盖整条真实线段。自动测试逐根验证相邻身体格正交相连、末段和 `dir` 同向、三种长度全部出现，并检查占格不重叠。

取消唯一解后，`solution_order` 只承担“证明这张图至少存在一条完整通关路径”的作用，不再限制玩家必须按它操作。第三关新增两组跃迁环、5 座折光/反相门和 P1/P2/P3 三道动态相位锁；相位锁分别在剩余箭数降到 30 / 20 / 11 条时解除。测试会直接验证锁开启时射线被阻挡、达到阈值后同一路径可以穿过，并要求每张第三关至少有一条开局射线真实受相位锁影响。

重开当前难度沿用相同 RUN 和地图；从启动选择页新开一局时生成新的 RUN。

pytest 内置的 `64 RUN × 3 关` 回归会连续生成 192 张随机地图，并逐张确认箭数、2–4 格真实箭体和完整可解性。终极困难还增加了双跃迁、相位锁阈值与实际参与度专项测试。

本轮另外对 16 个连续终极困难 RUN 做了机制诊断：箭数全部落在 38–42 条，16/16 完整可解，并且 16/16 至少有一条开局射线被相位锁真实阻挡。不同 RUN 的箭数、安全选择数量和受锁路径数量都有变化，仍保留随机局面，而不是退回固定谜题。
