- [ ] 在 `BLOG_DRAFT.md` 填姓名 / 学号；

## B. 代码仓库

- [ ] 在本人 GitHub/Gitee 创建仓库；
- [ ] 推送当前项目；
- [ ] 打开远程仓库确认 `README.md`、`src/`、`tests/`、`docs/` 都能看到；

```bash

npm start
```

- [ ] 桌面浏览器打开 `http://127.0.0.1:4173`；
- [ ] 点“进入箭域”；
- [ ] 至少完成第一关；
- [ ] 第二关确认能看到折光门；
- [ ] 连击到 100% 能量并试一次量子超载；
- [ ] F12 控制台无应用错误。

1. **首屏**：完整 HUD + 霓虹棋盘；
2. **第二关**：画面中出现折光门；
3. **量子超载 100%**：右侧能力按钮点亮；
4. **通关结果**：显示分数、最高连击和时间奖励。
