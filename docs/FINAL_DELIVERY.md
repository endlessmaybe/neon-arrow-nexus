## 任务总结

本轮把之前遗漏的 **基础模式** 真正补回规则层，并把启动流程改成“每次打开都先选玩法模式和难度”。基础模式现在是作业要求的单格四方向直线判阻；进阶模式继续保留 2–4 格真实随机长箭、折光/反相、双跃迁和阶段相位锁。难度仍严格只有简单 / 中等 / 终极困难三档。

在此基础上又补齐了之前漏掉的 **游戏中途切换难度**：实战侧栏现在有“切换难度 D”，不需要退出到启动页即可改为简单 / 中等 / 终极困难。

本轮进一步把实战侧栏整理为统一的 **矢量功能图标 + 文字 + 快捷键 + 悬停用途说明**，并针对 Pygame 渲染热路径做缓存/Surface 复用优化；同一 1600×1000 基准下单帧渲染耗时从 18.657 ms 降到 7.729 ms。同时补掉了一个稀有终极困难 RUN 的随机生成失败边界。

## 具体改动

- 新增 `create_basic_level()`：三档基础难度分别生成 18–22 / 28–34 / 40–48 支单格逻辑箭，统一 3 次容错，不加载进阶机关；
- 原 `create_level()` 保留为进阶生成器，继续使用真实占格的 2–4 格随机长箭体；
- 每次启动强制进入 `setup`，先选“基础 / 进阶”，再选“简单 / 中等 / 终极困难”，未完成两项选择不能直接进入游戏；
- 自动存档继续保留，但不会绕过启动选择；只有模式和难度与存档匹配时才显示“继续上次进度”；
- 新增中途难度切换面板：按 `D` 或点击侧栏按钮打开，`1 / 2 / 3` 直接切换三档难度，`D / Esc` 取消；切换时保留基础/进阶玩法模式，生成新的 RUN 与随机地图，并重置当前单关积分、连击、能量、生命和倒计时；
- 难度面板打开期间暂停倒计时和 AI 自动求解，同时屏蔽棋盘点击，避免选难度时游戏状态继续变化；
- 箭身可以直行，也可以在尾部随机出现 90° 转折，连接箭头的最后一段始终与箭头方向一致；
- 箭体本身参与真实占格和阻挡，不再使用单个箭头锚点加单格内 `visual_route` 的方案；
- 不同箭体不会共占格子，也不会占用折光门或跃迁端点；
- 第三关取消唯一解链，开局允许存在多条安全箭，玩家可以自由选择消除路线；
- 生成器仍保存并验证至少一条完整解序，保证随机地图可以通关；
- HUD 中不再显示“唯一解序”，第三关说明改为随机长箭阵。
- 悬停箭路只保留视觉高亮，不再提前显示安全/危险、阻挡点或正确路径；`H` 扫描提示及“安全出口/安全箭”入口已经移除；
- `V` 低动态模式会跳过启动动画、冻结持续装饰运动并减少粒子，且与音效设置一起持久化；
- 侧栏 8 个核心功能统一使用 Pygame 原生矢量线条图标；按钮同时保留文字和快捷键，悬停时显示用途说明卡片，不再要求玩家靠猜图标理解功能；
- 背景渐变/雾化、文本、光晕、棋盘网格、布局几何加入缓存；箭路、机关和粒子使用的全屏透明 Surface 改为跨帧复用，空粒子队列直接跳过 FX 层；
- 终极困难生成器的确定性重试预算最终提升到 64，并加入已知稠密 RUN `268185663`、`2111439849` 双回归，避免极少数情况下启动/切换难度直接生成失败；
- 整体界面做减法：删除扫描线、光谱丝带、轨道圈、透视网格、面板角标、多层玻璃高光和按钮扫描标记，只保留渐变、稀疏星点、必要状态色与单层边框；启动同步序列缩短到约 1.15 秒；
- 成功箭不再整根刚性平移。正常模式约 0.86 秒，前约 42% 由箭头先进入出口射线、箭身沿原折线逐段跟随并拉直，之后继续沿箭头方向出屏，后段再明显淡出；

- 新增 `py-07-difficulty-switch.png`，证明实战中的三档难度切换面板；
