# 霓虹箭域 · Neon Arrow Nexus

> 2026 秋软件工程个人作业（第二次），“一箭又一箭”小游戏的 Python / Pygame 双模式版本。

这份项目的最终实现唯一使用 **Python 3 + Pygame**。现在把作业要求的原始玩法和后续创新明确拆成两套规则：**基础模式**保留“单格四方向箭头 + 沿直线检查到边界”的题目主体，**进阶模式**才使用随机长箭、折光/反相、跃迁、相位锁、量子能量等扩展机制。两种模式都提供 3 个可通关关卡，并共用计分、计时、存档、AI 求解、离场动画和高清界面。

如果只想直接玩，双击：

```text
dist/NeonArrowNexus-Python.exe
```

这个 EXE 是用 PyInstaller 从 `main.py` 打出来的单文件 Windows 程序，不需要另外安装 Python 环境。

当前最终版默认以 **1600×1000 原生像素**启动，并在 Windows 下启用 **Per-Monitor V2 高 DPI 感知**。这样在系统 125% / 150% 缩放时，不再由 Windows 把低分辨率窗口二次放大，文字、细线、箭路边缘和 HUD 会保持清晰；窗口仍支持手动缩放。

## 1. 基础模式和进阶模式分开，并保留完整三关流程

每次打开程序都会先进入“玩法模式 + 难度”选择页，必须明确选择后才能开始。难度只有三档，不会生成第 4 档：

| 难度 | 基础模式 | 进阶模式 |
| --- | --- | --- |
| 简单 | 18–22 支单格箭，3 次容错 | 18–22 条 2–4 格长箭，5 点稳定度 |
| 中等 | 28–34 支单格箭，3 次容错 | 27–32 条长箭 + 90° 折光门 |
| 终极困难 | 40–48 支高密度单格箭，3 次容错 | 38–42 条长箭 + 折光/反相 + 双跃迁 + 3 道相位锁 |

三档难度同时对应第 1 / 2 / 3 关。启动页选择“简单”后进入正式三关流程：第 1 关清空后出现结算页，点击“进入第 2 关”继续，最终完成第 3 关后显示“三关全部完成”。启动页也允许直接选择中等或终极困难，从对应关卡开始正式流程，方便单独验收。

基础模式的箭在逻辑上 **只占一个格子**。点击后只沿箭头朝向逐格扫描：直到边界都没有遇到其它箭就可以离场；途中遇到任意箭则判为受阻。视觉上会画一小段格内箭身帮助辨认方向，但它不参与多格占用，也没有折光门、跃迁或相位锁。

进阶模式保留之前已经打磨过的随机长箭系统和高难机制。基础、进阶两套生成器都使用 RUN 种子，重新开始会换图，同一 RUN 可复现；代码层仍只接受难度索引 `0 / 1 / 2`，越界会直接拒绝。

## 2. 启动流程与基本玩法

- 启动后先选 **基础模式 / 进阶模式**，再选 **简单 / 中等 / 终极困难**；未完成两项选择时不会进入游戏。
- 如果本地有存档，只有先选中与存档一致的模式和难度，才会出现“继续上次进度”；也可以选择“新开此难度”。
- 点击一条箭路。
- 程序从箭头位置沿箭头方向计算完整飞行射线。
- 射线到边界前没有碰到其它箭路，则这条箭安全离场。
- 如果路径被挡住，会损失 1 点稳定度并清空连击。
- 清空本关所有箭路后进入结算页；非最终关可继续进入下一关，第 3 关结束后完成三关挑战。
- 稳定度耗尽或倒计时归零，本关失败。
- `U`：撤销上一步点击，恢复箭路、积分、生命、时间和能量状态。
- `A`：启动 AI 自动求解当前关，按生成器记录并验证过的解序逐步演示。
- `R`：重开当前关。
- `O`：能量达到 100% 后激活量子超载。
- `M`：开关程序内音效。
- `V`：开关低动态模式。关闭持续装饰运动并显著减少粒子运动，设置会和其它偏好一起保存。
- `D`：游戏过程中打开难度切换面板；面板内按 `1 / 2 / 3` 可切到简单 / 中等 / 终极困难，`D / Esc` 取消。切换时保留当前基础/进阶玩法模式，但会为新难度生成新的随机地图并重置当前单关进度。
- `B / N`：在启动页选择基础 / 进阶模式；`1 / 2 / 3`：选择三档难度；`Enter`：开始。
- 每次有效操作都会自动保存进度，下次启动可继续上次状态。

### 功能图标与用途

实战侧栏现在统一使用 **Pygame 矢量线条图标**，不依赖 emoji 或外部 PNG，因此在 125% / 150% DPI 和窗口缩放时仍保持清晰。鼠标悬停任一功能按钮，会出现用途说明卡片和对应快捷键。

| 图标语义 | 功能 | 快捷键 | 用途 |
| --- | --- | --- | --- |
| 三条调节轨 | 切换难度 | `D` | 保持当前基础/进阶玩法不变，在三档难度之间切换；切换后生成新地图并重置当前单关进度。 |
| 闪电 | 量子超载 | `O` | 能量达到 100% 后激活；下一次受阻箭可相位穿透一次且不扣稳定度。 |
| 回转箭头 | 撤销 | `U` | 恢复上一步手动点击前的箭路、积分、稳定度、时间和能量状态。 |
| 存档片 | 保存 | `S` | 立即写入本地存档，并保存音效与低动态偏好。 |
| 三节点网络 | AI 自动求解 | `A` | 计算并演示当前关的可行消除顺序；使用会扣分并影响星级评价。 |
| 环形箭头 | 重开本关 | `R` | 按同一 RUN 重置当前关，地图保持不变，方便重新判断。 |
| 运动线 | 低动态模式 | `V` | 冻结持续装饰运动、减少粒子效果，同时降低每帧渲染开销。 |
| 扬声器 | 音效 | `M` | 开关程序内音效，状态自动保存。 |

按钮的图标、文字、快捷键和悬停说明使用同一语义映射，避免出现“图标看得见但不知道干什么”的情况；禁用状态也会同步降低图标与文字强调度。

## 3. 进阶模式里的创新

以下机制 **只属于进阶模式**。基础模式不会加载这些机关，仍保持单格四方向直线判阻。

### 折光门

第二关开始出现折光门。射线进入后会顺时针或逆时针旋转 90°，所以不能只判断箭头正前方的一小段空位，而要算完整折线路径。

### 180° 反相门

第三关加入反相门。射线经过后会直接掉头，原本看起来即将离场的箭也可能重新穿回棋盘。

### 双跃迁环

第三关现在有 A / B 两组跃迁环。射线进入任一端点后会从对应另一端继续飞行，并保留当前方向。两组跃迁与折光、反相叠在一起后，同一箭路可能跨越棋盘多个区域。

### 分阶段相位锁

终极困难新增 P1 / P2 / P3 三道相位锁，分别在剩余箭数降到 30 / 20 / 11 条时解除。锁开启时会真实阻挡经过该格的射线，解除后同一路径才能穿过。生成器还会验证每张第三关至少有一条开局路径确实受相位锁影响，避免机制只停留在画面上。

### 棱镜充能与量子超载

部分箭路带棱镜标记，成功消除后会提供更多能量。能量达到 100% 后可以激活超载，让下一条被挡住的箭进行一次相位穿透，不损失稳定度。它不是无限容错，而是要通过前面的正确判断换取一次主动破局机会。

### 连击计分

连续正确操作会提高连击和得分，错误点击会清零连击。这样除了“能不能通关”，还有路线选择和分数优化的空间。

### 箭头离场反馈

鼠标悬停只做轻量视觉高亮，不会提前显示“安全 / 危险”、阻挡点、出口或正确路径，也不再提供 `H` 扫描提示入口。玩家需要自己判断箭路。成功点击后，箭不会瞬间消失：正常模式使用约 0.86 秒的离场过程，箭头先沿自身方向前进，箭身再沿原来的折线路径逐段跟随并被拉直离场，而不是整根箭刚性平移；后半段再平滑降低透明度。最后一根箭也会先完成这段可见离场，再出现过关结果面板。

### 低动态可访问模式

`V` 会切换低动态模式：持续背景/机制脉冲被冻结，消除粒子数量和速度降低，启动动画也会跳过。它不是单纯“把动画全删掉”，而是保留必要的颜色和文字反馈；低动态与音效设置都会写入自动存档。

### 终极困难随机长箭阵

第三关不再强制“唯一解”。它会在扩展后的 13×16 棋盘上生成 38–42 条真实占格的随机长箭体，并同时叠加 5 座折光/反相门、两组跃迁环和三道分阶段相位锁。稳定度仍只有 2，倒计时收紧到 120–136 秒；生成时还会避开“贴着边界直接朝外”的明显送分箭。玩家仍可以选择不同清除路线，难度来自高密度长箭、动态解锁时机和跨区域射线路径，而不是被迫背唯一答案链。

## 4. Python 随机关卡生成

两种模式都不是随机塞满箭以后碰运气。`neon_arrow/engine.py` 使用“反向构造”的思路：

1. 从空棋盘开始生成一条此时一定能够安全离场的箭；
2. 再逐步加入更早应该被处理的箭路；
3. 每次生成候选箭时，都调用真实的 `trace_ray()` 检查出口；
4. 完成后把构造顺序反过来，得到完整解序；
5. 自动测试重新按照解序逐条执行，确认整关确实能清空。

基础模式由 `create_basic_level()` 生成：每支箭逻辑上只占一个格子，三档难度分别生成 18–22 / 28–34 / 40–48 支箭，不加载任何进阶机关。视觉上仅绘制格内短箭身帮助读方向，这段短线不改变单格碰撞规则。

进阶模式由 `create_level()` 生成**真实占格的随机长箭体**。每根箭占 2–4 个连续格子，箭身可以直行，也可以在尾部随机出现 90° 转折；进入箭头的最后一段始终与 `dir` 完全一致。箭身本身就是碰撞实体。

生成时会逐格检查边界、其它箭体以及折光门、跃迁环、相位锁等保留格，因此不同箭不会共占同一个格子。视觉层直接连接这些真实占用格的中心点绘制长线条，鼠标命中也覆盖整段箭身。第三关采用 13×16 棋盘，为 38–42 条真实长箭和新增机制留出空间，同时保留关卡可解性和 RUN 可复现性。完整同类产品逐项对照见 `docs/MARKET_COMPARISON.md`。

因此随机性来自 RUN 种子和不同关卡盐值，但“随机”不会牺牲可解性。同一个 RUN 可以复现当时的地图，不同 RUN 会得到不同布局。

## 5. 画面与交互

全部画面由 Pygame 实时绘制：

- 深色低干扰渐变背景、稀疏星点与轻量色彩雾化；
- 启动时约 1.15 秒的简化同步序列，随后自然淡出进入主界面；
- 多层透明光晕箭体、白色核心高光和矢量箭头；
- 棱镜标记、旋转折光门、独立反相门视觉和脉冲跃迁环；
- 消除/碰撞粒子爆发；
- 实时 HUD：关卡、剩余箭路、稳定度、倒计时、积分、连击、量子能量；
- 鼠标点击 + `U / A / R / O / M / V / Enter / Space / Esc` 键盘操作；
- 实战侧栏提供“切换难度 D”，打开后倒计时和 AI 暂停，避免玩家在选择难度时继续消耗时间；
- 通关后按剩余稳定度和剩余时间给出 1–3 星评价；
- 自动存档位于当前 Windows 用户的 `LocalAppData/NeonArrowNexus/savegame.json`；
- 悬停只高亮当前箭，不提前泄露安全/危险结论，也没有“安全出口/安全箭”快捷提示；成功箭会沿自身方向真实飞出窗口并明显淡出；
- 面板、按钮和棋盘统一为低装饰深色层级，删除多余扫描线、轨道圈、角标和玻璃高光，只保留必要边框、状态色与按压反馈；
- 窗口可缩放，棋盘与侧栏会重新计算布局。

## 7. 从源码运行

推荐 Python 3.11+。本机最终验收使用 Python 3.13.1 和 pygame-ce 2.5.8。

```bash
python -m pip install -r requirements.txt
python main.py
```

如需运行测试或重新打包 EXE：

```bash
python -m pip install -r requirements-dev.txt
```

不想安装环境时，直接运行已经打好的：

```text
dist/NeonArrowNexus-Python.exe
```

## 8. 自动测试

```bash
python -m pytest -q tests/test_python_engine.py tests/test_python_app.py tests/test_python_features.py tests/test_assignment_acceptance.py
python main.py --headless-check
```

当前 Python 测试会检查：

- 每次新启动先进入模式 + 难度选择，未完成两项选择不能开局；
- 标准启动属于正式关卡流程而不是单关训练；第 1 关通关后可以加载第 2 关继续；
- 只有“简单 / 中等 / 终极困难”3 档难度；
- 基础模式全部为单格逻辑箭且不含折光、跃迁、相位锁；
- 进阶模式仍保留 2–4 格随机长箭和全部高级机制；
- 多组 RUN 下箭路数量落在各自区间；
- 每一关都能按生成器记录的解序完整清空；
- 第三关为 38–42 条随机长箭体，不再要求完整解序唯一；
- 第三关包含两组跃迁环、5 座折光/反相门以及 3 道按剩余箭数解除的相位锁；
- 相位锁阈值前后必须真实改变射线路径，且每张第三关至少有一条开局路线受相位锁影响；
- 连续抽样 64 个 RUN × 3 关进行生成压力回归；
- 初始局面既有安全箭，也有受阻箭，不是无脑全点；
- 同 RUN 可复现、不同 RUN 会变图；
- 90° 折光、180° 反相和跃迁环真实改变射线路径；
- Pygame 界面能在虚拟显示环境完成渲染；
- 实际调用点击逻辑后，安全箭真的从棋盘移除并计分。
- 撤销会恢复一次真实游戏操作；
- 自动存档可写入并重新载入；
- AI 自动求解能按解序清空当前关；
